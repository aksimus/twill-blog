# 🏗️ **Blade Template Structure - Blog System**

## **📁 Структура файлов**

```
resources/views/
├── layouts/
│   ├── blog-layout.blade.php          # Основной layout для блога
│   └── partials/                      # Частичные шаблоны
│       ├── head.blade.php             # Head секция с мета-тегами и CSS
│       ├── page-loading.blade.php     # Загрузочный спиннер
│       ├── header.blade.php           # Шапка сайта с навигацией
│       ├── nav.blade.php              # Навигационное меню
│       ├── footer.blade.php           # Подвал сайта
│       ├── back-to-top.blade.php      # Кнопка "Наверх"
│       └── scripts.blade.php          # JavaScript файлы
├── components/                         # Переиспользуемые компоненты
│   ├── breadcrumb.blade.php           # Хлебные крошки
│   ├── blog-post-meta.blade.php       # Мета-информация поста
│   ├── blog-post-content.blade.php    # Контент поста
│   └── blog-post-sidebar.blade.php    # Боковая панель поста
└── site/blog/
    └── blog-single.blade.php          # Страница отдельного поста
```

## **🔧 Основные компоненты**

### **1. `blog-layout.blade.php`**
- **Назначение**: Основной layout для всех страниц блога
- **Особенности**: 
  - Использует `@yield('content')` для основного контента
  - Поддерживает `@yield('title')` и `@yield('meta')` для SEO
  - Включает все необходимые частичные шаблоны

### **2. `head.blade.php`**
- **Назначение**: Управление head секцией
- **Особенности**:
  - Динамический заголовок страницы
  - SEO мета-теги через `@yield('meta')`
  - Все CSS файлы и стили загрузки

### **3. `header.blade.php`**
- **Назначение**: Шапка сайта с навигацией
- **Особенности**:
  - Переключатель темы (светлая/темная)
  - Адаптивное мобильное меню
  - Логотип и основные кнопки

### **4. `nav.blade.php`**
- **Назначение**: Навигационное меню
- **Особенности**:
  - Мега-меню для разделов
  - Выпадающие списки
  - Активные состояния

## **🎯 Переиспользуемые компоненты**

### **1. `<x-breadcrumb>`**
```blade
<x-breadcrumb :items="[
    ['url' => route('home'), 'title' => 'Home'],
    ['url' => route('blog.index'), 'title' => 'Blog'],
    ['url' => '#', 'title' => 'Post Title']
]" />
```

### **2. `<x-blog-post-meta>`**
```blade
<x-blog-post-meta :post="$post" />
```
- Отображает категорию, дату, лайки, комментарии
- Информацию об авторе с аватаром

### **3. `<x-blog-post-content>`**
```blade
<x-blog-post-content :post="$post" />
```
- Основной контент поста
- Теги в конце

### **4. `<x-blog-post-sidebar>`**
```blade
<x-blog-post-sidebar :post="$post" />
```
- Время чтения
- Кнопки социальных сетей
- Кнопка "Нравится"

## **📝 Использование в контроллерах**

### **Пример контроллера:**
```php
public function show(BlogPost $post)
{
    $relatedPosts = BlogPost::where('category_id', $post->category_id)
        ->where('id', '!=', $post->id)
        ->limit(3)
        ->get();

    return view('site.blog.blog-single', compact('post', 'relatedPosts'));
}
```

### **Передача данных в шаблон:**
```php
// В контроллере
$post = BlogPost::with(['category', 'tags', 'author', 'comments.user'])->findOrFail($id);

// В шаблоне
<x-blog-post-meta :post="$post" />
<x-blog-post-content :post="$post" />
```

## **🎨 Кастомизация**

### **1. Изменение стилей**
- Все стили находятся в `head.blade.php`
- CSS переменные для цветов и размеров
- Поддержка темной/светлой темы

### **2. Добавление новых компонентов**
```bash
# Создание нового компонента
php artisan make:component BlogPostCard

# Использование в шаблоне
<x-blog-post-card :post="$post" />
```

### **3. Расширение layout**
```blade
@extends('layouts.blog-layout')

@section('title', 'Custom Title')
@section('meta')
    <meta name="description" content="Custom description">
@endsection
```

## **🚀 Преимущества новой структуры**

### **✅ Модульность**
- Каждый компонент отвечает за свою функциональность
- Легко переиспользовать в других частях сайта
- Простое тестирование отдельных компонентов

### **✅ Поддержка**
- Четкое разделение ответственности
- Легко найти и исправить проблемы
- Простое добавление новых функций

### **✅ Производительность**
- Частичные шаблоны кэшируются отдельно
- Компоненты могут быть оптимизированы независимо
- Меньше дублирования кода

### **✅ SEO и доступность**
- Структурированные мета-теги
- Семантическая разметка
- Поддержка ARIA-атрибутов

## **🔍 Отладка и тестирование**
