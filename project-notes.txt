Frontend Blog functionality:

- multilingual ( en, es, ru)  . en - default should be without prefix e.g. /blog /es/blog /ru/blog

- category page  => fields: title + slug + rich text description: e.g. /blog/category/{slug} /es/blog/category/{slug} /ru/blog/category/{slug}
- tag page  =>  title + slug + rich text description:   e.g. /blog/tag/{slug} /es/blog/tag/{slug} /ru/blog/tag/{slug}

- post page => title + slug + rich text description + main category + tags list:   e.g. /blog/{slug} /es/blog/{slug} /ru/blog/{slug}


Blog administration panel Twill CMS based, available on /cms url
